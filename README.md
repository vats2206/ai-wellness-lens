# Vision Fit Insights

Premium UI & Hero Section Requirements

The website must have a premium startup aesthetic similar to Apple, Linear, Stripe, and modern AI startups.

Hero Section

Create a fullscreen hero section with a looping background video.

Video Requirements:

Fullscreen video background

autoPlay

loop

muted

playsInline

absolute inset-0 w-full h-full object-cover z-0

Use the supplied video URL as the hero background.

The video should provide all visual depth.

Do not add:

gradient overlays

decorative blobs

particles

excessive effects

Keep it cinematic and minimal.

Fonts

Instrument Serif

--font-body: 'Inter', sans-serif;
